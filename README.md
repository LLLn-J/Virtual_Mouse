# Contactless Mouse Control

A touch-free mouse control system that uses 2D cameras to track hand gestures, enhancing hygiene in public spaces. Developed during June 2022 – Aug. 2022.

## Features
- **Gesture Recognition**: Uses OpenCV to detect and process 5+ hand gestures.
- **Cross-Platform Support**: Works on both Windows and macOS.
- **Easy Installation**: Packaged as `.exe` and `.dmg` with an auto-configuration environment.

## Installation
1. Download the latest release for your OS:
   - Windows: [Download `.exe`](https://github.com/LLLn-J/Virtual_Mouse/blob/main/Virtual_Mouse_Setup1.0.2.exe)
   - macOS: [lost]😭
2. Run the installer and follow the on-screen instructions.

## Usage
- Launch the application.
- Position your hand within the camera's view.
- Use predefined gestures to control the cursor.

## Technologies Used
- **Python** for core development
- **OpenCV** for gesture recognition
- **Windows/macOS APIs** for system integration
